# Resume font assets

The resume uses character subsets of Adobe Source Han Sans SC (Regular, Medium) and Source Han Serif SC (SemiBold), distributed under the SIL Open Font License 1.1. Copyright and license notices are preserved in the fonts; see the two license files in this directory.

Sources:
- https://github.com/adobe-fonts/source-han-sans/tree/release/OTF/SimplifiedChinese
- https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese

Subsets contain the current resume text, ASCII, and common Chinese punctuation. Their internal family names are Yanxin CV Sans and Yanxin CV Serif. CSS retains system fallbacks for characters added in future revisions. Regenerate the subsets when adding substantial text.
