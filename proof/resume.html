代表性项目深度解读

xyVL-0.8B　·　具身智能视觉-语言基座模型 2026　·　主导研发
  • 问题定义：在 1B 以内小模型规模上，实现可媲美中等规模 VLM 的具身理解、空间推理与第一视角任务能力，服务家庭情感陪伴机器人的端侧实时推理需求。
  • 数据管线 (xyData)：聚合 HuggingFace / GitHub / ModelScope 50+ 开源数据集（涵盖 Text / Image / Video / Robotics / Autonomous Driving），统一为 13 类任务 schema 的 Unified Schema；xyJudge 系统中 Heuristic Tagger 完成 dedup / 语言识别 / 规则过滤，Model-as-Judge 完成 Quality / Difficulty / Repetition / Complexity / Coherence 五维结构化打标；45M 原始样本精选至 18M 高质量数据，按任务类型与难度系数做 mixture 配比。
  • 训练管线：以 Qwen3.5-0.8B 为 backbone，三段式后训练 —— ① SFT (xyData-SFT) 打牢指令跟随；② On-Policy Distillation (xyData-OPD)，以 Qwen3.5-27B 作 on-policy 教师对小模型能力蒸馏；③ GRPO RL (xyData-RL) 配合自研 Reward System (推理 / 安全 / 导航 / 规划四维度) 做强化学习对齐。
  • 结果与落地：在 General VQA / Multi-Image / Spatial / Video / Embodied / Egocentric VQA 六大类 32 项 benchmark 中 28 项领先；Token 密度大幅提升，已应用于公司家庭陪伴机器人产品线。
